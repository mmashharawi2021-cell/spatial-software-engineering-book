# EX-001

Illustrative excerpt; not a standalone runnable example.

```text
import geopandas as gpd

points = gpd.read_file("data/facilities.gpkg", layer="facilities")
zones = gpd.read_file("data/zones.gpkg", layer="zones")

assert points.crs is not None and zones.crs is not None
points = points.to_crs(zones.crs)
joined = gpd.sjoin(points, zones[["zone_id", "geometry"]], predicate="within")
print(joined.groupby("zone_id").size())
```
