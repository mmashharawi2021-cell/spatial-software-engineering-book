# EX-002

Illustrative excerpt; not a standalone runnable example.

```text
-- 1) نفّذ في بيئة تدريب قبل إنشاء الفهرس، وسجّل الخطة والزمن
EXPLAIN (ANALYZE, BUFFERS)
SELECT z.id, count(f.id) AS facilities_count
FROM zones z
LEFT JOIN facilities f
  ON ST_Intersects(z.geom, f.geom)
GROUP BY z.id;

-- 2) أنشئ الفهارس المكانية وحدّث إحصاءات المخطط
CREATE INDEX IF NOT EXISTS zones_geom_gix
  ON zones USING GIST (geom);
CREATE INDEX IF NOT EXISTS facilities_geom_gix
  ON facilities USING GIST (geom);
ANALYZE zones;
ANALYZE facilities;

-- 3) أعد الاستعلام نفسه وقارن Index Scan / Buffers / Execution Time
EXPLAIN (ANALYZE, BUFFERS)
SELECT z.id, count(f.id) AS facilities_count
FROM zones z
LEFT JOIN facilities f
  ON ST_Intersects(z.geom, f.geom)
GROUP BY z.id;
```
