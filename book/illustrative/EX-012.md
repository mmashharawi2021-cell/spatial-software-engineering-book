# EX-012

Illustrative excerpt; not a standalone runnable example.

```text
CREATE FUNCTION touch_feature_updated_at() RETURNS trigger AS $$
BEGIN
  NEW.updated_at := now();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER features_touch_updated_at
BEFORE UPDATE ON features
FOR EACH ROW EXECUTE FUNCTION touch_feature_updated_at();
```
